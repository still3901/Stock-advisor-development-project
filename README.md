# 머신러닝을 활용한 SOXL에 관한 소셜데이터 분석 및 주주매매의견 제시

## 프로젝트 배경 요인

### <소셜미디어인 레딧에서 일반투자자들이 작당하여 GameStop의 주가를 폭등시킨 사례> 
-	투자자들이 소셜미디어로 작당하여 ‘GameStop’주식을 집단매수해 주가를 급등시키고, 공매도하여 펀드에 큰 손실을 입힌 사태가 발발함.
-	단순한 차트 분석만으로는 주가를 완벽하게 예측할 수 없음을 파악함.

## 프로젝트 결과물

### <주식 커뮤니티의 뉴스 헤드라인과 댓글을 심층 분석하여 SOXL의 당일 종가 예측하는 모델 개발>
-	주가의 변동성이 심한 미국 반도체 업종에 집중적으로 투자하는 ETF인 ‘SOXL’종목 채택함.
-	주식 커뮤니티인 Investing닷컴, Reddit, 네이버주식에서 비정형데이터이자 실시간 데이터인 뉴스 헤드라인과 댓글을 크롤링하여 전처리 후 감성분석 실시.
-	당일 종가를 예측하여 투자자에게 5단계로 나눠진 의견(강력매도, 매도, 중립, 매수, 강력매수)을 제시.

### <투자자들이 쉽게 접근할 수 있는 인터페이스 제공>
-	예측된 종가를 고려해 투자자에게 5단계로 나눠진 의견(강력매도, 매도, 중립, 매수, 강력매수)을 제시.
-	streamlit구현을 통해 사용자가 이해하기 어려운 금융 프로젝트에 대해 시각적으로 보여주어 프로젝트 파악 및 투자의견 제시에 용이하게 하였으며, 만들어놓은 모델을 돋보이게 시각화.
